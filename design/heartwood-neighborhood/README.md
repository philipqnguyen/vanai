# Heartwood shared city geometry

`client/src/heartwood-neighborhood.ts` retains the procedural trees, rooms, rails, planters and geometry helpers used by the live city. See [CITY.md](CITY.md) and [UPPER.md](UPPER.md) for the retained production implementation and walking QA.

The isolated three-home neighborhood viewer, its concept painting, concept board and study screenshots were retired by user authorization on 2026-09-22. Normal `/?zone=heartwood` and `/?heartwood-city` remain, with the production avatar and shared city geometry.
