# Caerdun production architecture

The production kit and its rebuild library are documented in [GAME-KIT.md](GAME-KIT.md).
Preserve `game-kit/`, `tools/art/caerdun_game_kit.py`, `tools/art/caerdun_game_audit.py`, and `client/public/models/caerdun/`, including their existing texture inputs.

The isolated harbor study, its Blender drafts, concept board and study renders were retired by user authorization on 2026-09-22. The old city the kit was built for was replaced by the Sea Gate fortress on 2026-10-08 (CAERDUN.md); the kit still serves eight other zones.
